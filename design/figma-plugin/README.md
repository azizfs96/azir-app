# إضافة Figma — شاشات سوبرماركت Azir

تبني شاشات واجهة السوبرماركت كطبقات Figma أصلية قابلة للتحرير (إطارات، مستطيلات،
نصوص) بنفس قيم التطبيق في `flutter/lib/features/grocery/grocery_theme.dart`:
الألوان، المسافات، الزوايا، والخطوط (IBM Plex Sans Arabic).

## التشغيل (مرة واحدة، ثلاث نقرات)

1. افتح **تطبيق Figma على الماك** (الاستيراد من ملف لا يعمل في المتصفح) وافتح أي ملف.
2. من القائمة: **Plugins → Development → Import plugin from manifest…**
   واختر الملف `design/figma-plugin/manifest.json` من هذا المستودع.
3. **Plugins → Development → Azir Market screens → Run**.

تظهر صفحة جديدة باسم «Azir Market — supermarket» فيها خمسة إطارات:

| الإطار | المحتوى |
|---|---|
| Home | الرئيسية كما تظهر على الشاشة (402 × 874) مع شريط التنقل |
| Docked tools (on scroll) | شريط البحث وحبيبات التصنيفات بعد التمرير |
| Categories | صفحة الأقسام: الشريط الجانبي وشبكة عمودين |
| Home – full scroll | الرئيسية كاملة بطولها الحقيقي |
| Design tokens | لوحة الألوان والملاحظات |

كما تُنشأ أنماط ألوان باسم `Azir Market/…` في لوحة الأنماط.

## ملاحظات

- الخط: إن لم يكن «IBM Plex Sans Arabic» متاحًا في حسابك تستخدم الإضافة Inter تلقائيًا.
- صور المنتجات والتصنيفات رموز تعبيرية (كما في المتجر التجريبي)؛ استبدلها بصورك بسحبها فوق المربعات.
- إعادة التشغيل تضيف صفحة جديدة ولا تعدّل الصفحة السابقة.
- لتعديل البيانات (الأسماء، الأسعار، التصنيفات) حرّر الثوابت في أعلى `code.js` وأعد التشغيل.
